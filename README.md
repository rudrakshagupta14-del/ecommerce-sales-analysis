# E-Commerce Sales Analysis

## Project Overview

This project analyzes an e-commerce sales dataset to understand sales,
profit, customers, products, and order performance.

The project was completed as a data analytics practice project. It uses
Excel, SQL, and Power BI to clean data, explore business questions, and
present the results in an interactive dashboard.

## Tools Used

-   **Microsoft Excel** -- data cleaning, pivot tables, and initial
    analysis
-   **Power Query** -- data preparation and transformation
-   **PostgreSQL** -- storing data and writing SQL queries
-   **Power BI** -- creating the interactive dashboard

## Project Workflow

1.  **Data cleaning:** Checked the dataset, corrected date and number
    formats, and created useful columns such as total cost and order
    processing days.
2.  **Excel analysis:** Used summary calculations, pivot tables, and
    charts to explore the data.
3.  **SQL analysis:** Imported the cleaned data into PostgreSQL and
    wrote queries to analyze sales, profit, products, customers,
    regions, and shipping modes.
4.  **Power BI dashboard:** Built a three-page dashboard to present the
    main results.

## Dashboard Pages

-   Total Sales
-   Total Profit

-   Sales and Profit Target Achievement

### 2. Sales Performance & Operational Insights

-   Sales performance by market
-   Category and sub-category contribution
-   Shipping mode distribution
-   Order priority analysis
-   Discount analysis

### 3. Product Performance & Customer Insights

-   Top 10 products
-   Top 10 customers
-   Profit by sub-category
-   Customer segment analysis

## Key Analysis Areas

-   Which regions and markets generate the most sales?
-   Which product categories contribute the most profit?
-   Which products and customers perform best?
-   How do sales change over time?
-   How are orders distributed across shipping modes and priorities?
-   How do discounts relate to sales and profit?

## How to View the Project

1.  Open the screenshots to see the dashboard pages.
2.  Open the `.pbix` file using Microsoft Power BI Desktop.
3.  Open the SQL folder to review the queries.
4.  Open the Excel workbook to view the initial analysis.

## Notes

-   The dashboard targets are assumed values used for analysis. They are
    not official company targets.
-   Some records contain missing profit values. These should be
    considered when interpreting profit-related results.
-   `Order Processing Days` represents the number of days between the
    order date and ship date. It does not represent the final delivery
    time.
